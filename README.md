# Anthropeum Scorebook

My daily [Anthropeum](https://anthropeum.com) scores.

**[Open the dashboard](https://carterlagasse.github.io/anthropeum/)**

Push a day's result to the repo root as `M_D`, and a GitHub Action files it under `data/` and updates `index.html`.

The previous README and charts are in [`archive/old-dashboard`](archive/old-dashboard/README.md).
